# Roadmap

Planned improvements for LeafleKT. Not a commitment, priorities may shift.

## Planned

- **Custom Tile Providers** — plug in any XYZ tile URL without forking
- **Offline Tile Cache** — download and serve tiles locally
- **Provider Fallback Chains** — auto-switch tile provider on failure
- **Showcase App** — standalone demo app on Play Store + App Store
- **Better GeoJSON Support** — feature properties, style-per-feature, click events
- **Vehicle Tracking Utilities** — smooth marker animation along polyline paths
- **Native Rendering Research** — evaluate MapLibre or similar for fully offline native rendering
